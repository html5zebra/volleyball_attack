# SpikeLab — разбор атакующего удара по видео

Один файл `index.html`, работает в браузере телефона. Видео никуда не отправляется, ИИ‑запросов и ключей нет: поза распознаётся на устройстве (MediaPipe Pose), рекомендации — по правилам.

## Что делает
- Находит прыжок в ролике до 40 с, разбирает 3 секунды вокруг него (до 60 замеров/с, кадр уменьшается до 640 px).
- Фазы: разбег, отталкивание, прыжок, замах, контакт, приземление.
- Тайминг: контакт относительно пика прыжка (рано / вовремя / поздно), потеря высоты, пас → отрыв → контакт.
- Три главные правки с подсказкой и упражнениями; безопасность приземления — в приоритете.
- История, график прогресса, сравнение двух попыток, экспорт JSON, копирование разбора текстом.

## Физика
- Центр масс считается по сегментам тела; в полёте его траектория — парабола с ускорением g.
- Высота прыжка: h = g·t²/2 по времени от отрыва до вершины параболы (не зависит от масштаба кадра). Вершина даёт пик прыжка точнее одного кадра.
- Проверка масштаба: ускорение в пикселях сравнивается с g; при расхождении с масштабом по росту показывается предупреждение (например, недекларированное замедление).
- Высота удара над полом и над сеткой, угол вылета, перегрузка при приземлении, угловая скорость локтя.

## Инструменты разбора
График (центр масс, скорость кисти, угол локтя) с курсором, стробоскоп фаз, «призрак» эталонной попытки (★ в истории), ручные метки фаз, увеличение.

## Съёмка
Сбоку со стороны бьющей руки, штатив, 6–8 м, 1080p / 60 fps, обычный режим (не Slo‑mo), всё тело в кадре от последних шагов до приземления.

## Настройка порогов
Все пороги — в объекте `CONFIG.T` в начале скрипта. `src: 'coach'` — распространённый тренерский ориентир, `src: 'heur'` — эвристика, подбирается под себя. Правила рекомендаций — массив `RULES`.

## Ограничения
2D‑поза с одного ракурса: разворот плеч относительно таза не измеряется; контакт определяется автоматически по пику скорости кисти и требует проверки вручную; мяч не отслеживается.
